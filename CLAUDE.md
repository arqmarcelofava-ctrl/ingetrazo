# Instruções para o Claude Code neste projeto

Este é um fork do IngeTrazo (GPL-3.0) com um spike de **BIM leve só com
extensões** em andamento na branch `spike/viabilidade-bim`.

**Antes de qualquer coisa, leia `docs/CONTINUAR.md`.** Ele diz quem é o
usuário, o que já foi feito, o que foi aprendido e o que fazer a seguir. Se o
usuário disser apenas "continue" ou "continuar", siga a seção 5 desse arquivo.

Resumo das regras: responda em **português do Brasil**, em linguagem simples
(o usuário não é de informática); mostre **imagens** sempre que possível; não
altere `core/` nem `tools/`; use só símbolos públicos e marque com `FRAGILE`
qualquer interno; **nunca faça commit de arquivos de cliente** (a pasta
`modelos/` é ignorada pelo Git de propósito).
