02 · As regras do jogo

Quatro regras para o teste valer

01

Só extensões

Tudo em plugins e docs. O núcleo do programa (core e tools) não foi alterado.

02

Só o que é público

O que não é contrato do programa fica marcado FRAGILE, para sabermos o que pode quebrar.

03

Licença limpa

Tudo GPL-3.0 ou mais nova, sem dependência nova no projeto.

04

Nenhum dado de cliente

Projetos reais ficam fora do repositório. As imagens aqui são de modelos sintéticos.

IngeTrazo BIM leve · de onde partimos até onde chegamos

03 / 19

As regras serviram para o resultado ser confiável: se tivéssemos mexido no núcleo, a conclusão seria "dá para mexer no programa", não "dá para estender". A pasta modelos/ é ignorada pelo Git de propósito, para nenhum arquivo de cliente subir.
